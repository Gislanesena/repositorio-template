# 👀 Para os Organizadores

Guia rápido de como acompanhar o repositório do 1º Hackathon FATEC Itaquera.

---

## O que conferir e onde encontrar

### 📄 Documentos
Clique em qualquer arquivo `.md` na lista do repositório para ler:

| O que ler | Onde está |
|-----------|-----------|
| Página principal do evento | `README.md` |
| Edital completo | `docs/EDITAL.md` |
| Guia de GitHub para participantes | `docs/GUIA-PARTICIPANTE.md` |

---

### 📋 Tasks do desafio
Clique na aba **Issues** para ver todas as tarefas que os times podem executar.
Use o filtro **Labels** para navegar por categoria (`obrigatório`, `frontend`, `bonus`, etc.).

---

### 📊 Andamento geral
Clique na aba **Projects** para ver o Kanban com todas as tasks organizadas por status:
`Backlog → To Do → In Progress → Review → Done`

---

### 💬 Dúvidas dos participantes
Clique na aba **Discussions** para acompanhar as perguntas abertas e as respostas dos mentores.
